# chest-xray-pneumonia-detection

Project Description
This project investigates pneumonia detection using both classical machine learning and deep learning approaches on chest X-ray images. The aim is to compare how traditional models (XGBoost, Random Forest, MLP) and deep learning architectures (Advanced CNN, VGG16, ResNet50, DenseNet121) perform in detecting pneumonia while minimizing misclassification of healthy patients.

The notebook includes:

Data preprocessing and feature extraction, including HOG features for classical models

Training and evaluation of multiple models, both classical and deep learning

Visualization of performance metrics (accuracy, precision, recall, F1-score, AUC)

Confusion matrices and ROC curves to analyze model strengths and weaknesses

Analysis of results highlighting which models are most reliable and the trade-offs between classical and deep learning approaches

Key Focus: Understand the differences in performance between classical ML models and deep learning models for medical image classification, with DenseNet121 emerging as the most balanced and reliable model.

This repository is ideal for:

Students and researchers exploring classical vs deep learning methods

Practitioners evaluating model performance for healthcare applications

Anyone interested in practical applications of ML and DL for medical diagnostics
